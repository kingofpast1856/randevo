# Randevo Website — Final

Site yayındaymış gibi hazırlandı.

## İndirme bağlantısını eklemek

Sadece `index.html` dosyasını aç ve şu ifadeyi ara:

`BURAYA_INDIRME_LINKI`

İki yerde geçer. İkisini de gerçek indirme linkinle değiştir.

Örnek:

`href="https://ornek.com/randevo.apk"`

Başka bir değişiklik gerekmez.
